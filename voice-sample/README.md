# voice-sample/

Drop **one clip of you speaking** here (`.wav`, `.mp3`, or `.m4a`):

```
voice-sample/my-voice.m4a
```

Tips for a good clone:

- **60–90 seconds** is plenty. Longer is not better.
- **Speak the way you'd narrate** — calm, clear, natural pace. Tone matters far
  more than what you say; read anything.
- **Clean audio wins.** A quiet room and your laptop mic beat a long, noisy file.
- Mono is fine. render.sh picks the first audio file it finds here.

Your sample stays on your machine — this folder is git-ignored (except this note).
